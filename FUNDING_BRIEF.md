# First-Line Funding Brief

## Product Thesis

Advanced rocketry education is fragmented across textbooks, agency handbooks, technical reports, regulations, specialized software, and operational lessons. This project tests whether those elements can be joined into one traceable research-learning environment.

## Current Evidence

- Public, runnable source code
- 14 technical modules and 84 research seminars
- 14 interactive screening laboratories
- Primary-source registry
- Automated curriculum and route tests
- Independent expert-review instrument
- Explicit non-affiliation and non-operational safety scope

## What Is Not Yet Proven

- Independent technical approval
- Learning efficacy
- Market demand or willingness to pay
- Flight-level fidelity
- Regulatory acceptance
- Sustainable maintenance economics

## Milestone-Based Funding

### Phase 1: Independent Validation

Obtain a credentialed review, publish findings, correct blockers and high-severity issues, and issue a reviewed release.

### Phase 2: Computational Credibility

Replace selected screening models with benchmarked solvers, convergence evidence, uncertainty propagation, and reproducible cases.

### Phase 3: Learning Efficacy

Run a structured graduate/professional pilot and measure transfer, error detection, retention, and technical-defense performance.

### Phase 4: Sustainable Platform

Add content governance, releases, accessibility, hosted deployment, institutional pilots, and a durable maintenance model.

Funding should be released against evidence from each phase, not against claims of NASA equivalence or endorsement.
